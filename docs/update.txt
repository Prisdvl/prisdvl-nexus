# 六、最重要：多租户 / 数据隔离

这是正式产品必须解决的问题。

所有用户数据必须按照 user_id / tenant_id 正确隔离。

例如：

```text
User A
 ├── KB A
 ├── Documents A
 ├── Agents A
 ├── Conversations A
 └── Tools A

User B
 ├── KB B
 ├── Documents B
 ├── Agents B
 ├── Conversations B
 └── Tools B
```

必须验证：

```text
A 不能读取 B 的 KB
A 不能读取 B 的 Document
A 不能读取 B 的 Agent
A 不能调用 B 的 Agent
A 不能读取 B 的 Conversation
A 不能修改 B 的资源
```

特别检查：

* API 参数直接传 resourceId
* 越权查询
* 越权修改
* 越权删除
* Agent → Knowledge Base
* Chat → Agent
* RAG → Knowledge Base
* Vector Search metadata filter

不能只依赖前端隐藏按钮。

必须在后端强制校验。

增加对应 API / integration / E2E tests。
