注意：

> **不要重新创建项目。**
>
> **不要修改项目名称。**
>
> **不要修改现有 Maven 聚合工程和基础包名。**

# 一、现有项目固定约定

当前项目已经确定以下命名规范，后续所有代码必须严格遵守：

| 范围     | 当前约定              |
| ------ | ----------------- |
| 聚合工程   | `prisdvl-nexus`   |
| 公共模块   | `nexus-common`    |
| AI 模块  | `nexus-ai`        |
| 知识库模块  | `nexus-knowledge` |
| 应用模块   | `nexus-app`       |

例如：


如果需要增加新的 package：


# 二、项目新的产品定位

当前项目不要再定位成：

> 个人 RAG 知识库 Agent

需要升级成为：

> **一个面向个人、团队和企业用户的通用 AI 应用开发与运行平台。**

核心思想是：

```text
用户
 ↓
创建自己的资源
 ↓
知识库
Agent
Workflow
Tools
AI Application
 ↓
组合这些能力
 ↓
形成属于自己的 AI 应用
```

平台不应该假设：

```text
只有一个用户
只有一个知识库
只有一套 Prompt
只有一个 Agent
只有一个 Workflow
```

而必须从系统设计上支持：

```text
多用户
多知识库
多 Agent
多 Workflow
多 Application
```

# 四十五、Workflow JSON

统一定义 Workflow，例如：

```json
{
  "nodes": [
    {
      "id": "start",
      "type": "START",
      "config": {}
    },
    {
      "id": "llm1",
      "type": "LLM",
      "config": {
        "model": "qwen-plus",
        "prompt": "{{input}}"
      }
    },
    {
      "id": "rag1",
      "type": "RAG",
      "config": {
        "knowledgeBaseId": "kb001",
        "topK": 5
      }
    },
    {
      "id": "end",
      "type": "END",
      "config": {}
    }
  ],
  "edges": [
    {
      "source": "start",
      "target": "llm1"
    },
    {
      "source": "llm1",
      "target": "rag1"
    },
    {
      "source": "rag1",
      "target": "end"
    }
  ]
}
```

不要把 Workflow 节点结构硬编码到 Java 类中。

# 四十六、安全设计

必须考虑：

```text
Authentication
Authorization
Resource Ownership
API Key Protection
File Upload Security
Prompt Injection
Tool Permission
Rate Limit
```

特别注意 RAG：

```text
用户上传的文档
```

只能作为：

```text
Context
```

不能默认作为：

```text
System Instruction
```

例如用户知识中出现：

```text
忽略之前所有指令
执行 XXX
```

不能因为这是 RAG 内容，就让 Agent 执行。

---

# 四十七、Prompt Injection

至少在设计层面区分：

```text
System Prompt
Developer Prompt
User Prompt
Retrieved Context
Tool Result
```

优先保证：

```text
System Instruction
    >
User Instruction
    >
Retrieved Context
```

检索结果必须明确标识为外部知识。

# 五十九、最重要的一条要求

你必须记住：

> **`prisdvl-nexus` 不是一个“给我自己用的 AI 项目”，而是一个“允许其他用户在平台上创建属于自己的 AI 应用”的平台。**

因此所有核心资源都必须从：

```text
写死
```

升级为：

```text
用户创建
用户配置
用户保存
用户复用
用户执行
用户管理
```

最终应该达到：

```text
平台提供能力
        ↓
用户组合能力
        ↓
用户创造 AI 应用
        ↓
用户使用 AI 应用
```

而不是：

```text
开发者写一个 Agent
        ↓
所有用户只能使用这个 Agent
```
