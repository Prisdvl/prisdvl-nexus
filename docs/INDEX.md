## 权威顺序（查什么，先看哪）

| 要查的东西 | 去哪 |
|---|---|
| 系统现在到底怎么跑 | `architecture.md` **§0** |
| 某个接口的路径 / 请求体 | `api.md` 对应章节（认「已实现」标注） |
| 某张表的字段 | `database.md`（核心表定稿） |
| 为什么这么选 / 否掉了什么方案 | `decisions.md`（按 ADR 编号） |
| 版本矩阵、某次实测的证据 | `decisions-appendix.md`（按 B.x 编号） |
| 有没有某个安全机制 | `security.md` + 文末「未实现」清单 |

## 文档自身的冲突声明（引用时优先遵守）

- `architecture.md`：「与现状冲突时，以 §0 与 decisions.md 附录 B 的实测记录为准」
- `security.md` / `agent.md` / `rag.md`：只记录代码中真实存在的机制，未确认者标注「未确认」
- `docs/archive/README.md`：归档区是过程产物，**不要当成规范读**
