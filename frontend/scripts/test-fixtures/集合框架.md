# Java 集合框架

PRISDVL_E2E_COLLECTION_FRAMEWORK_2026

## List
List 是有序集合，允许重复元素。主要实现有 ArrayList、LinkedList。

## Set
Set 不允许重复元素。HashSet 基于哈希表实现，TreeSet 基于红黑树。

## Map
Map 存储键值对。HashMap 允许 null 键，TreeMap 按键排序。

## Queue
Queue 用于队列实现。ArrayDeque 可以做栈和队列。

## Java 8 HashMap 底层结构
Java 8 中 HashMap 采用数组 + 链表 + 红黑树结构。

数组是主体，每个位置称为桶（bucket）。链表解决哈希冲突：当多个键的哈希值映射到同一个桶时，节点以链表形式串联。当红黑树化条件满足时，链表转换为红黑树以提升查询性能。

## HashMap 树化条件
当链表长度达到 8，并且数组长度达到 64 时，链表会转换为红黑树。如果数组长度小于 64，即使链表长度达到 8，也优先进行扩容而不是树化。

## HashMap 容量与负载因子
HashMap 默认初始容量为 16，默认负载因子为 0.75。扩容阈值等于容量乘以负载因子，因此默认初始容量 16 时扩容阈值为 12。当元素数量超过扩容阈值时，HashMap 会扩容为原来的两倍。
